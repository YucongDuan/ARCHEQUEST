# ARCHEQUEST

ARCHEQUEST is a deterministic-contract system for classifying and answering 64
recurrent ultimate philosophical questions across 11 local problem worlds. It is
compatible with the determinacy firewall and relational-role discipline of
DIKWP-MESH 6.2B, while remaining a separately packaged public reference system.

## Determinacy

A philosophical answer is "determinate" when the question, hidden premises,
answer scope, counterworlds, D/I/K/W/P role use, evidence grade, and reopening
conditions are frozen and hash-addressed. Determinacy is not universal metaphysical
completion. The reference dataset contains no C5 final-completion claim.

## Run

```bash
python -m archequest run
python -m archequest show AQ-001
python -m archequest list --category "心灵与意识"
python -m archequest export outputs
```

## Outputs

The engine produces validated answer contracts, a question summary, cross-question
relations, a hash-chain ledger, metrics, and a deterministic run proof.

## Boundaries

This author-side reference implementation does not certify any religion, afterlife,
artificial consciousness, political order, or moral doctrine as universally complete.
It must not be used as an automatic high-impact decision authority.
